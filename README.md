# Mark

> 面向持续更新的开源知识源，提供安静的个人阅读、标注与回访空间。

Mark 计划把多个 GitHub 文档仓库汇入一个个人书架：跟随上游更新，阅读 Markdown，保存自己的划线与笔记，并在需要时检索或提问。产品面向单用户，在家用 NAS 上通过 Docker 部署。本轮原型只覆盖电脑 Web 浏览器访问，不开发独立桌面客户端。

**当前状态：规划与原型阶段。** 仓库目前只有项目文档、原型图与许可证，尚无可运行的应用、镜像或安装命令。以下能力是目标，不代表已经实现。

## 核心方向

- **多来源书架**：一个知识库管理多个独立 GitHub 仓库，每个来源独立同步。
- **上游只读**：原始内容与个人划线、笔记、阅读状态分别保存。
- **看见变化**：按来源和文档查看新增、修改、删除，并识别需要复核的标注。
- **阅读优先**：检索与 AI 问答辅助阅读，不喧宾夺主。

项目尚未提供快速开始步骤。待首个可运行版本落地后，README 将补充经过验证的本地启动、Docker 部署和备份恢复说明。
