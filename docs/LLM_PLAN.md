# Mark LLM 接入与增强规划

更新：2026-10-12。状态：**设置页与审核后的 N1–N5 已实现，本地自动化和浏览器验证通过；真实模型质量与远程运行待验收**。

## 1. 背景与边界

Mark 是个人知识源阅读器：公开 GitHub 仓库只读同步，文档具有路径和发布版本，笔记、书签及阅读记录独立保存。LLM 用于帮助理解、提炼和复核，输出须能回到原文；用户主动触发调用，保存个人内容须明确确认。

继续使用电脑 Web、React + Fastify + SQLite，以及原生 Node/systemd 部署。模型在配置的服务端运行，Mark 不要求 GPU。单一活动模型、统一兼容接口即可支持本轮功能。

## 2. 现状与本轮交付

| 能力 | 状态与实际边界 |
| --- | --- |
| 文档 Ask | 默认严格仅本篇；跨来源显式选择 1–3 个来源。关键词取证，最多 6 个片段，每片段最多 850 字符；校验引用编号，不承诺逐句语义正确性 |
| 本篇范围与覆盖 | Reader 提交已读 SHA；生成前锁定上下文。本篇无关键词命中时可使用起始片段，仍明确有限覆盖，不冒充全文总结 |
| 引用版本 | 返回来源、路径、发布 SHA、实际片段；打开只读版本正文及同版本图片。改名、删除、仓库切换与来源移除后仍可核查，版本不可读时明确失败 |
| 选段解释 | 工具条主动触发；核对对应版本中的选段与位置，只发送本篇选段及附近上下文 |
| 更新影响解读 | 差异页主动触发；读取固定同步记录的前后版本、真实变化片段和相关标注摘录，只给解释与复核建议 |
| LLM 界面配置 | 已实现地址、模型、密钥、开关、测试、保存、放弃修改；保存立即影响后续请求 |
| 模型接入 | 兼容 `POST {baseUrl}/chat/completions`，提交 `model/messages/stream:false`，解析文本回答；协议参考 [官方接口](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create) |
| 验证范围 | 自动化和本地模拟模型服务用于验证功能；实际服务商、真实密钥、费用与目标服务器发布另行验收 |

## 3. 设置页契约（本轮实现）

入口：**Settings → LLM 接入**。

| 字段 / 操作 | 规则 |
| --- | --- |
| 启用模型功能 | 关闭后保留配置；后续 Ask 不调用模型，阅读和关键词搜索继续可用 |
| API 接入地址 | HTTP/HTTPS 完整基础地址，保留 `/v1` 等实际路径；不要填完整 `/chat/completions`；地址不包含账号、密码、查询参数或锚点 |
| 模型名称 | 手填服务商模型 ID；“已配置”只表示字段保存，不代表连接已验证 |
| API 密钥 | 按服务要求填写；读取不返回密钥。留空保持已有密钥，勾选清除才删除；无密钥服务可以直接留空 |
| 地址变化 | 若已有密钥，须重新填写或明确清除，避免把旧密钥自动带到新地址 |
| 测试连接 | 使用当前表单和适用的已有密钥，发送一条简短消息，不发送文档或笔记，不保存配置；会产生一次模型调用 |
| 保存配置 | 在服务端 SQLite `settings.model_config` 保存完整配置，立即生效并在重启后保留；新请求用新配置，已发出的请求不自动重跑 |
| 配置优先级 | 尚无界面配置时读取 `MARK_MODEL_*`；保存后整个界面配置优先，包括关闭和明确清空密钥，不能回落到环境密钥 |
| 放弃修改 | 恢复到最后读取或保存的配置，不调用模型，不写入数据库 |
| 多标签页 | `revision` 防止旧页面覆盖新配置；冲突提示重新加载，保留当前输入 |

模型密钥保存在部署端运行数据库中，不使用浏览器持久化存储，不随 GET 响应或服务商错误正文回传；包含配置的数据库备份也须按运行数据保管。

### 加载与异常

| 状态 | 界面及数据行为 |
| --- | --- |
| 首次读取 | 局部骨架屏，其他设置可用；读取失败给重新加载入口 |
| 未配置 / 关闭 | 显示“未配置 / 已停用”；填写地址和模型后可测试，启用后可保存为活动配置 |
| 测试 / 保存中 | 展示进度文字，禁用重复操作和字段编辑，避免把测试结果贴到另一份输入上 |
| 测试成功 | 显示模型与耗时；草稿仍提示未保存，状态不冒充持久连接监控 |
| URL / 字段无效 | 原位提示，保留输入，不部分更新配置 |
| 密钥 / 模型错误 | 分别提示密钥无权限、接口或模型不存在；不改变应用登录状态 |
| 限流 / 不可达 / 超时 | 提示原因，允许手动重试；25 秒请求超时，不自动重复付费调用 |
| JSON / 回答格式不兼容 | 明确兼容接口问题，保留旧配置，不把原始服务商正文显示给用户 |

## 4. 审核后的范围与实施顺序

依据：阅读优先、个人记录独立、上游变化可理解、单机易维护。用户已确认本轮按下表开发；各项按实际验证关闭。

| 顺序 | 本轮必要功能 | 最小交付与验收 |
| --- | --- | --- |
| N1 | Ask 范围控制 | 默认本篇；跨来源须主动选择来源。本篇请求不得混入其他文档，缺少证据明确提示 |
| N2 | 固定版本引用 | 引用包含文档、路径、SHA、实际片段；可打开只读版本正文。更新、改名、删除或切换仓库后仍能核查旧版本；无法读取则明确失败 |
| N3 | 异常与取消 | 加载、失败、超时、取消均有反馈；禁重复提交，取消/切换后丢弃迟到结果；客户端断开时向模型传播取消，实际计费由模型服务决定 |
| N4 | 选段解释 | Reader 选中文字后主动触发；先在对应版本核对选段，解释只使用本篇必要上下文，不修改原文、标注或笔记 |
| N5 | 更新影响解读 | Updates 差异页主动触发；固定同一同步记录的前后版本和真实变化，解释含义及可复核标注建议，不自动改变标注或阅读状态 |

本篇导读降为可选；笔记草稿、跨来源结构化对照延后。阅读自测移出当前版本，与首版不包含考试、课程类流程的边界保持一致。语义检索、缓存和调用统计在出现可测量需求后评估。

## 5. 具体架构与契约

沿用 `server/ask.ts`、`server/model-client.ts`、`server/model-settings.ts` 和 SQLite；不新增通用任务平台或草稿表。本轮增加共享的版本/证据读取模块，供版本正文、Ask 与差异解读复用。

| 接口 | 契约 |
| --- | --- |
| `POST /api/ask` | `scope=document` 使用文档 ID 与已读 SHA；`scope=sources` 必须指定 1–3 个来源。缺省仅在提供文档 ID 时允许本篇范围 |
| `GET /api/documents/:id/version?sha=&path=` | 验证该来源已发布的 SHA 和该版本中的文档路径；只读显示版本与引用片段，不保存阅读位置、书签或标注 |
| `GET /api/documents/:id/version/assets?sha=&path=&asset=` | 相对图片按已验证的文档路径和同一 SHA 读取；资源缺失明确返回错误 |
| `POST /api/documents/:id/explain` | 已读 SHA、选段与近似位置；空/过长/无法定位/歧义分别拒绝，不向模型发送未验证文本 |
| `POST /api/updates/:id/explain` | 文档 ID；服务端读取该同步记录的实际前后路径、SHA、变化片段及相关标注摘录 |

上下文与请求在生成开始时固定；生成期间同步不改变引用依据。长文按有限片段处理，明确“局部覆盖”，不声称全文总结。选段上限 2000 字符；更新解读按变更附近片段取证，大片段截断必须提示。模型只返回解释与建议，没有个人记录写入权限。

正文与相对资源从同一 Git SHA 读取。来源移除后，既有版本引用仍可核查；不再发起该来源的本篇 Ask/选段解释。版本丢失给出明确错误，不自动改跳当前正文。历史正文内的相对文档链接暂只展示文字，外部链接与页内链接可用；不冒充完整的历史仓库导航。回答仅在当前页面会话中保留，刷新不承诺回答历史。

## 6. 实施与验收清单

### 本轮界面接入

| ID | 验证动作 | 通过条件 / 证据 |
| --- | --- | --- |
| C01 | 无界面配置时读取设置 | 正确读取环境回退；GET 不含密钥；未配置显示空态 |
| C02 | 保存地址、模型、密钥并请求 Ask | 无需重启，实际请求使用新地址/模型/密钥，引用仍通过原有校验 |
| C03 | 修改草稿后测试、再放弃修改 | 请求使用草稿；测试不保存，不发送业务片段；放弃后恢复原配置 |
| C04 | 留空、替换、清除密钥，更换地址 | 留空保持；替换生效；清除后不回落到环境密钥；新地址须明确处理密钥 |
| C05 | 关闭并重启服务 | 配置保持关闭；Ask 不调用模型；搜索和阅读可用 |
| C06 | 注入 401/403、404、429、5xx、无效 JSON、空回答、超时和网络失败 | 有明确受控错误；不回传服务商私有正文、不部分保存，允许手动重试 |
| C07 | 两标签页持有同一旧 revision 后分别保存 | 第二次返回 409，不覆盖第一份配置，界面保留输入并提示重新加载 |
| C08 | 在电脑浏览器操作加载、测试、保存、失败和重试 | 状态与数据一致；禁重复请求；刷新后保留配置，密钥输入为空；无布局溢出或运行时错误 |
